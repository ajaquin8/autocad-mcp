# Tool reference

Generated by `scripts/gen_tool_docs.py` from the server's tool registry; do not edit by hand.
Tools: **54**. Read-only tools are marked (read-only). Lengths are drawing units, angles degrees.

See [[Projects/AutoCAD-MCP/index]] for status and [[Research/AutoCAD API gotchas]] for API lessons.

## Session and drawings

- **`acad_status`** (read-only): Connect to AutoCAD and report which AutoCAD it is (e.g. "AutoCAD 2026"), the open drawings and which of them this server may edit. Call this first. Name the AutoCAD by the "autocad" field; "autocad_version" is AutoCAD's raw release number. Parameters: `start_if_needed`.
- **`list_documents`** (read-only): List open drawings (name, path, unsaved changes, read-only, editable).
- **`allow_edit_document`**: Unlock an EXISTING drawing so drawing tools may change it. Parameters: `name`.
- **`new_drawing`**: Create a new drawing this server may edit. It becomes the active drawing. Parameters: `template`.
- **`open_drawing`**: Open a drawing file. It stays locked for edits until the user asks you to change it (allow_edit_document). A drawing that is already open is returned as it is. Parameters: `path`, `read_only`.
- **`save_document`**: Save an editable drawing, in place or to a new path (SaveAs). Parameters: `path`, `overwrite`, `name`.
- **`close_document`**: Close a drawing this server created. Never closes the user's own drawings. Parameters: `name`, `discard_changes`.

## Inspect

- **`drawing_info`** (read-only): Summarize a drawing: units, extents, layer and layout counts, and model space entity counts by type and by layer. Parameters: `name`.
- **`query_entities`** (read-only): Find entities by type and/or layer, in model space or on one layout (paper space, where title blocks and viewports live). Returns handle, type, layer and bounding box; use get_entity for full details. Parameters: `object_type`, `layer`, `limit`, `offset`, `layout`, `name`.
- **`get_entity`** (read-only): Full details of one entity: coordinates, sizes, text, block attributes or dimension measurement, depending on its type. Parameters: `handle`, `name`.
- **`zoom_extents`**: Zoom the active view to show the whole drawing. Changes the user's view, not the drawing. Parameters: `name`.
- **`capture_view`** (read-only): Screenshot the AutoCAD window so you can SEE the drawing. Use after drawing steps (zoom_extents first if the new geometry may be off screen). Parameters: `max_width`.

## Layers

- **`list_layers`** (read-only): List the drawing's layers with color, linetype, lineweight and on/frozen/locked state. Parameters: `name`.
- **`add_layer`**: Create a layer, or update the color/linetype/lineweight of an existing one. Parameters: `layer`, `color`, `linetype`, `lineweight`, `description`, `plot`, `name`.
- **`set_current_layer`**: Make a layer current, so new objects from the user land on it too. Parameters: `layer`, `name`.

## Draw

- **`draw_line`**: Draw a line. Parameters: `start`, `end`, `layer`, `name`.
- **`draw_polyline`**: Draw a 2D polyline (LWPOLYLINE) through points. Parameters: `points`, `closed`, `bulges`, `layer`, `name`.
- **`draw_rectangle`**: Draw an axis-aligned rectangle as a closed polyline. Parameters: `corner`, `opposite_corner`, `layer`, `name`.
- **`draw_circle`**: Draw a circle. Parameters: `center`, `radius`, `layer`, `name`.
- **`draw_center_mark`**: Draw a centre mark: two crossing lines through the centre of a hole or arc, reaching a little past the curve. Both lines are one undo step. Use a centre-line layer. Parameters: `center`, `radius`, `extension`, `layer`, `name`.
- **`draw_arc`**: Draw an arc counter-clockwise from start_angle to end_angle. Parameters: `center`, `radius`, `start_angle`, `end_angle`, `layer`, `name`.
- **`add_text`**: Add single-line text (TEXT) with its insertion point at position. Parameters: `text`, `position`, `height`, `rotation`, `layer`, `name`.
- **`add_mtext`**: Add multiline text (MTEXT). Its top-left corner is at position. Parameters: `text`, `position`, `width`, `height`, `layer`, `name`.

## Dimensions and leaders

- **`add_dimension`**: Add a linear dimension between two points, using the current dimension style. Parameters: `first`, `second`, `text_position`, `kind`, `rotation`, `text_override`, `layer`, `name`.
- **`add_radial_dimension`**: Dimension a circle or arc by its diameter (Ø) or radius (R), using the current dimension style. Parameters: `center`, `point_on_curve`, `kind`, `leader_length`, `text_override`, `layer`, `name`.
- **`add_leader`**: Add a multileader (a callout): an arrow at the first point, a line through the next, and text at the last, using the current multileader style. Good for notes such as "1/4" DIA THRU, 4 PLACES". Parameters: `points`, `text`, `layer`, `name`.

## Blocks

- **`list_blocks`** (read-only): List block definitions in the drawing (not layouts or xrefs), with their attribute tags. Parameters: `include_anonymous`, `name`.
- **`insert_block`**: Insert a block reference, optionally filling in its attributes and dynamic properties. For a dynamic block, "bbox" is what the block shows at its current size (measured from a temporary exploded copy, attribute text left out); AutoCAD's own box also counts hidden sizes. Parameters: `block`, `position`, `scale`, `rotation`, `attribute_values`, `layer`, `dynamic_properties`, `layout`, `name`.
- **`set_block_attributes`**: Change attribute values of an existing block reference. Parameters: `handle`, `values`, `name`.
- **`get_block_properties`** (read-only): Read a block reference's dynamic properties (value, allowed values) and attributes (value, invisible). Works on any open drawing. Parameters: `handle`, `include_hidden`, `name`.
- **`set_block_properties`**: Set dynamic block properties by name, in the order given, as one undo step; if any value is refused, all are put back. Distances take numbers or inch fractions ("1 1/4"). Lists (e.g. Size) must use one of the allowed values (see get_block_properties). Parameters: `handle`, `properties`, `regen`, `allow_hidden`, `name`.
- **`measure_block`**: Measure what a block reference actually shows (after its visibility state, stretches and arrays): extents and object counts, and optionally each visible line, polyline, arc and circle. Works by exploding a temporary copy, which is deleted again, so it only runs on drawings this server may edit. Attribute text is counted but not measured. Parameters: `handle`, `include_geometry`, `name`.
- **`add_attribute_definition`**: Add an attribute definition (ATTDEF) in model space: a fill-in field such as a sheet number or a part mark. Use it while drawing a block in its own drawing: save that drawing, insert it by path with insert_block, and the block has these attributes to fill in. Parameters: `tag`, `position`, `height`, `prompt`, `default`, `invisible`, `constant`, `preset`, `lock_position`, `layer`, `name`.

## Edit

- **`move_entities`**: Move entities by an offset. Parameters: `entity_handles`, `offset`, `name`.
- **`change_properties`**: Change the layer, color or linetype of entities. Parameters: `entity_handles`, `layer`, `color`, `linetype`, `name`.
- **`delete_entities`**: Delete entities. All handles are checked before anything is deleted; the user can bring them back with one Ctrl+Z (U), but this server cannot. Parameters: `entity_handles`, `name`.

## Plot

- **`plot_pdf`** (read-only): Plot one layout to a PDF with its own page setup, using the DWG To PDF device. No geometry is changed and the layout tab the user had open is restored, but AutoCAD marks the drawing as having unsaved changes after a plot (verified 2026-10-29). Parameters: `path`, `layout`, `overwrite`, `name`.

## Drawing settings

- **`get_drawing_variables`** (read-only): Read the drawing settings that set_drawing_variables can change (dimension scale, units, linetype scale...). Parameters: `name`.
- **`set_drawing_variables`**: Change drawing settings saved in the drawing, e.g. {"DIMSCALE": 24, "DIMLUNIT": 4, "LUNITS": 4, "LTSCALE": 12} for a 1/2"=1'-0" architectural drawing. DIM* values are also copied into the active dimension style, and model space dimensions on that style are rebuilt with them. One undo step; restored if any value fails. Parameters: `variables`, `name`.
- **`set_current_styles`**: Make styles that are already in the drawing (usually from its template) current, so new dimensions, leaders and text use them. Nothing already drawn changes. One undo step. Parameters: `dimension_style`, `multileader_style`, `text_style`, `name`.
- **`add_text_style`**: Create a text style, or change the font and proportions of an existing one (text already drawn in it follows). One undo step. Parameters: `style`, `font`, `height`, `width_factor`, `oblique_angle`, `make_current`, `name`.
- **`add_dimension_style`**: Create a dimension style from the current dimension settings plus the changes given here, or apply the changes to an existing style. The style becomes the current one, so new dimensions use it. One undo step. Parameters: `style`, `variables`, `text_style`, `arrowhead`, `name`.
- **`add_multileader_style`**: Create a multileader style for add_leader, or change an existing one. Give it the plot scale factor so callouts come out the same size on paper as dimensions: 4 for 3" = 1'-0", 48 for 1/4" = 1'-0", like DIMSCALE. One undo step. Parameters: `style`, `scale`, `text_height`, `arrow_size`, `text_style`, `make_current`, `name`.

## Sheets and viewports

- **`list_layouts`** (read-only): List the drawing's sheets (layouts) in tab order, with the viewports and block references (such as the title block) on each. Use the handles with get_entity and set_block_attributes. Parameters: `name`.
- **`add_viewport`**: Add a viewport to a sheet (layout) that shows model space at an exact scale, centred on a model point. The sheet becomes the current layout tab. One undo step. Parameters: `layout`, `corner`, `opposite_corner`, `view_center`, `scale`, `layer`, `lock`, `name`.
- **`set_page_setup`**: Set a sheet's page setup: plot device, paper size and, if given, the plot style table. The sheet then plots its whole layout at 1:1 without rotation, so pick the paper whose first number is the width: "ANSI full bleed B (17.00 x 11.00 Inches)" is a landscape 17 x 11 sheet. One undo step. Parameters: `layout`, `paper`, `plot_style`, `device`, `name`.

## block_editor

- **`open_block_editor`**: Open the Block Editor on a block of a drawing this server created (-BEDIT with the name as a LISP string, so names with spaces work). The other Block Editor tools need it open; close it with close_block_editor. Parameters: `block`, `name`.
- **`close_block_editor`**: Close the Block Editor, saving the block first (BSAVE, then BCLOSE) or discarding the changes. If BCLOSE still asks Save/Discard, it is answered. If AutoCAD shows a dialog instead (it once showed "Block - Changes Not Saved"), the error names it and the user has to answer it. Parameters: `save`, `name`.
- **`add_linear_parameter`**: Add a linear parameter in the open Block Editor (BPARAMETER Linear): the distance property users see as `label` (e.g. "Width"), measured from start to end, with its line through label_location. One grip (the default) sits at the end point. Returns "pick_point", a point on the parameter's line for add_stretch_action. Parameters: `label`, `start`, `end`, `label_location`, `grips`, `name`.
- **`add_stretch_action`**: Add a stretch action in the open Block Editor (BACTION Stretch) to the parameter drawn through parameter_pick (use pick_point from add_linear_parameter; it must be on screen, so the view is zoomed to extents first). Objects with points inside `frame` are stretched; other selected objects are MOVED, so select only what should follow. Parameters: `parameter_pick`, `frame`, `select`, `end`, `multiplier`, `exclude_types`, `location`, `name`.
- **`lock_attribute_positions`**: Lock the position of every attribute definition in a block definition, so the Block Editor's actions can select them (unlocked ones are filtered out). Call it with the Block Editor closed, before adding actions. One undo step; drawings this server may edit only. Parameters: `block`, `name`.
- **`check_dynamic_block`**: Test a dynamic block: insert a temporary reference, set its properties case by case, measure what it shows (exploded copy, attribute text left out) and compare the change from the base state with what each case expects. The reference is deleted again. Run it with the Block Editor closed, after saving the block. Parameters: `block`, `cases`, `base_properties`, `position`, `tolerance`, `name`.

## commands

- **`run_command`**: Run one AutoCAD command with a list of answers to its prompts, in a drawing this server created (the edit guard and busy check apply). Use it for prompt-driven commands no other tool covers, e.g. Block Editor commands (BPARAMETER, BACTION) or -PURGE. AutoCAD is never left waiting: if the command still wants input after the last answer it is cancelled, and if it ended early or was cancelled the drawing goes back to how it was (UNDO mark). The result has a transcript of the prompts. Parameters: `command`, `inputs`, `name`, `undo_on_failure`, `timeout_seconds`.

## control

- **`cancel_command`**: Cancel a command or prompt this server left open in AutoCAD (for example a scripted command stopped at "Select objects:"), which makes AutoCAD reject every other call. Works even then: it hands AutoCAD two Ctrl+C through a window message, not COM. Refuses unless AutoCAD's active drawing is one this server created (also one its scripts created: the ownership record is read again), so it cannot cancel the user's work in their own drawings. It cannot close a dialog; when one is open it names it. Do not use it while the user is working in that drawing.
