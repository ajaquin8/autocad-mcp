# Tool reference

Generated by `scripts/gen_tool_docs.py` from the server's tool registry; do not edit by hand.
Tools: **38**. Read-only tools are marked (read-only). Lengths are drawing units, angles degrees.

See [[Projects/AutoCAD-MCP/index]] for status and [[Research/AutoCAD API gotchas]] for API lessons.

## Session and drawings

- **`acad_status`** (read-only): Connect to AutoCAD and report which AutoCAD it is (e.g. "AutoCAD 2026"), the open drawings and which of them this server may edit. Call this first. Name the AutoCAD by the "autocad" field; "autocad_version" is AutoCAD's raw release number. Parameters: `start_if_needed`.
- **`list_documents`** (read-only): List open drawings (name, path, unsaved changes, read-only, editable).
- **`allow_edit_document`**: Unlock an EXISTING drawing so drawing tools may change it. Parameters: `name`.
- **`new_drawing`**: Create a new drawing this server may edit. It becomes the active drawing. Parameters: `template`.
- **`open_drawing`**: Open a drawing file. It stays locked for edits until the user asks you to change it (allow_edit_document). A drawing that is already open is returned as it is. Parameters: `path`, `read_only`.
- **`save_document`**: Save an editable drawing, in place or to a new path (SaveAs). Parameters: `path`, `overwrite`, `name`.
- **`close_document`**: Close a drawing this server created. Never closes the user's own drawings. Parameters: `name`, `discard_changes`.

## Inspect

- **`drawing_info`** (read-only): Summarize a drawing: units, extents, layer and layout counts, and model space entity counts by type and by layer. Parameters: `name`.
- **`query_entities`** (read-only): Find entities by type and/or layer, in model space or on one layout (paper space, where title blocks and viewports live). Returns handle, type, layer and bounding box; use get_entity for full details. Parameters: `object_type`, `layer`, `limit`, `offset`, `layout`, `name`.
- **`get_entity`** (read-only): Full details of one entity: coordinates, sizes, text, block attributes or dimension measurement, depending on its type. Parameters: `handle`, `name`.
- **`zoom_extents`**: Zoom the active view to show the whole drawing. Changes the user's view, not the drawing. Parameters: `name`.
- **`capture_view`** (read-only): Screenshot the AutoCAD window so you can SEE the drawing. Use after drawing steps (zoom_extents first if the new geometry may be off screen). Parameters: `max_width`.

## Layers

- **`list_layers`** (read-only): List the drawing's layers with color, linetype, lineweight and on/frozen/locked state. Parameters: `name`.
- **`add_layer`**: Create a layer, or update the color/linetype/lineweight of an existing one. Parameters: `layer`, `color`, `linetype`, `lineweight`, `description`, `name`.
- **`set_current_layer`**: Make a layer current, so new objects from the user land on it too. Parameters: `layer`, `name`.

## Draw

- **`draw_line`**: Draw a line. Parameters: `start`, `end`, `layer`, `name`.
- **`draw_polyline`**: Draw a 2D polyline (LWPOLYLINE) through points. Parameters: `points`, `closed`, `bulges`, `layer`, `name`.
- **`draw_rectangle`**: Draw an axis-aligned rectangle as a closed polyline. Parameters: `corner`, `opposite_corner`, `layer`, `name`.
- **`draw_circle`**: Draw a circle. Parameters: `center`, `radius`, `layer`, `name`.
- **`draw_center_mark`**: Draw a centre mark: two crossing lines through the centre of a hole or arc, reaching a little past the curve. Both lines are one undo step. Use a centre-line layer. Parameters: `center`, `radius`, `extension`, `layer`, `name`.
- **`draw_arc`**: Draw an arc counter-clockwise from start_angle to end_angle. Parameters: `center`, `radius`, `start_angle`, `end_angle`, `layer`, `name`.
- **`add_text`**: Add single-line text (TEXT) with its insertion point at position. Parameters: `text`, `position`, `height`, `rotation`, `layer`, `name`.
- **`add_mtext`**: Add multiline text (MTEXT). Its top-left corner is at position. Parameters: `text`, `position`, `width`, `height`, `layer`, `name`.

## Dimensions and leaders

- **`add_dimension`**: Add a linear dimension between two points, using the current dimension style. Parameters: `first`, `second`, `text_position`, `kind`, `rotation`, `text_override`, `layer`, `name`.
- **`add_radial_dimension`**: Dimension a circle or arc by its diameter (Ø) or radius (R), using the current dimension style. Parameters: `center`, `point_on_curve`, `kind`, `leader_length`, `text_override`, `layer`, `name`.
- **`add_leader`**: Add a multileader (a callout): an arrow at the first point, a line through the next, and text at the last, using the current multileader style. Good for notes such as "1/4" DIA THRU, 4 PLACES". Parameters: `points`, `text`, `layer`, `name`.

## Blocks

- **`list_blocks`** (read-only): List block definitions in the drawing (not layouts or xrefs), with their attribute tags. Parameters: `include_anonymous`, `name`.
- **`insert_block`**: Insert a block reference, optionally filling in its attributes. Parameters: `block`, `position`, `scale`, `rotation`, `attribute_values`, `layer`, `name`.
- **`set_block_attributes`**: Change attribute values of an existing block reference. Parameters: `handle`, `values`, `name`.

## Edit

- **`move_entities`**: Move entities by an offset. Parameters: `entity_handles`, `offset`, `name`.
- **`change_properties`**: Change the layer, color or linetype of entities. Parameters: `entity_handles`, `layer`, `color`, `linetype`, `name`.
- **`delete_entities`**: Delete entities. All handles are checked before anything is deleted; the user can bring them back with one Ctrl+Z (U), but this server cannot. Parameters: `entity_handles`, `name`.

## Plot

- **`plot_pdf`** (read-only): Plot one layout to a PDF with its own page setup, using the DWG To PDF device. No geometry is changed and the layout tab the user had open is restored, but AutoCAD marks the drawing as having unsaved changes after a plot (verified 2026-10-29). Parameters: `path`, `layout`, `overwrite`, `name`.

## Drawing settings

- **`get_drawing_variables`** (read-only): Read the drawing settings that set_drawing_variables can change (dimension scale, units, linetype scale...). Parameters: `name`.
- **`set_drawing_variables`**: Change drawing settings saved in the drawing, e.g. {"DIMSCALE": 24, "DIMLUNIT": 4, "LUNITS": 4, "LTSCALE": 12} for a 1/2"=1'-0" architectural drawing. DIM* values are also copied into the active dimension style, and model space dimensions on that style are rebuilt with them. One undo step; restored if any value fails. Parameters: `variables`, `name`.
- **`set_current_styles`**: Make styles that are already in the drawing (usually from its template) current, so new dimensions, leaders and text use them. Nothing already drawn changes. One undo step. Parameters: `dimension_style`, `multileader_style`, `text_style`, `name`.

## Sheets and viewports

- **`list_layouts`** (read-only): List the drawing's sheets (layouts) in tab order, with the viewports and block references (such as the title block) on each. Use the handles with get_entity and set_block_attributes. Parameters: `name`.
- **`add_viewport`**: Add a viewport to a sheet (layout) that shows model space at an exact scale, centred on a model point. The sheet becomes the current layout tab. One undo step. Parameters: `layout`, `corner`, `opposite_corner`, `view_center`, `scale`, `layer`, `lock`, `name`.
