# AutoCAD-MCP knowledge vault

The Obsidian vault for AutoCAD-MCP. It lives **inside the code repository** so every machine stays in sync, the same way as the inventor-mcp vault.

- **Open in Obsidian:** "Open folder as vault", then pick `<repo>/knowledge`.
- **Sync:** git. The Obsidian Git plugin is not installed in this vault yet (inventor-mcp's vault has it); add it from Obsidian's community plugins if you want the same automatic commits.
- **Rules:** follow [[wiki-protocol]] (evidence labels, dated sections, one writer at a time, link check). Log every change in [[Change log]].
- **Scope:** AutoCAD-MCP only. Notes about a particular employer's or client's environment stay out of this vault.
